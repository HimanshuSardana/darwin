Give your agent a computer.

darwin is a self-hosted agent app built on eve — the agent works inside its own microVM, drives a real browser you can watch live, and ships with a streaming chat UI you host yourself.

View on GitHub Quickstart
What you get
  • microVM workspace: every built-in shell command runs in an isolated lightweight VM rooted at /workspace — nothing it does touches your machine
  • Live browser: the agent drives a real Chromium on your desktop and you watch it stream into a floating panel inside the chat
  • Plan / build modes: planning turns are read-only by tool allowlist — bash and write_file literally aren't callable — then build turns work the plan
  • Two workspaces, one agent: flip between the sandboxed VM and your host machine; host commands pause and wait for your approval
  • Skills & slash commands: /grill interrogates your task before a line of code exists, and skills load on demand
  • Bring your own model: any OpenAI-compatible gateway — darwin ships wired to OpenCode Go's Responses API with a 200k context window
  • Chat app included: streaming chat, sessions, workspaces and sign-in — a Next.js app in apps/web
  • Deploys to Vercel: eve deploy links the project and ships the agent
How it works

Two halves, one repo. The agent is a directory of files under agent/ — instructions, tools, skills, sandbox config — that eve compiles and runs. The app is a normal Next.js project that talks to it over eve's channel auth and streams tokens back to the browser.

# darwin at a glance you ──▶ apps/web (Next.js chat UI · auth · sessions) │ stream ▼ eve channel ──▶ agent/ (eve: instructions · tools · skills) │ ┌─────────────────┼──────────────────────┐ ▼ ▼ ▼ microVM /workspace host Chromium approval-gated host bash · read · write live-streamed local_bash · export_file
Quickstart
# clone and install $ git clone https://github.com/HimanshuSardana/darwin.git $ cd darwin && npm install # agent TUI (eve reloads your changes as you work) $ eve dev # chat UI → http://localhost:3000 $ npm run dev:web

FAQ

What exactly is darwin?

An agent app: an eve agent (instructions, tools, skills, sandbox — all plain files) plus a Next.js chat frontend. You can read the whole thing on GitHub.

Does the agent touch my machine?

Not by default. Built-in shell and file tools run inside the microVM. Tools that do reach the host — local_bash, local_write — pause and wait for your approval first, and browser clicks and fills are approved once per session.

How does the browser panel work?

Chromium runs on the host (so the window is real and visible), driven through snapshot references rather than raw DOM. Screenshots stream over an internal API into a floating, draggable, fullscreenable panel in the chat.

Which model does it use?

Whatever OpenAI-compatible endpoint you point it at. The default is OpenCode Go's gateway, called through the Responses API — swap the provider in a few lines of agent/agent.ts.

Where does it run?

Locally with eve dev, deployed to Vercel with eve deploy. The web app is a standard Next.js project, so it hosts anywhere Next does.
